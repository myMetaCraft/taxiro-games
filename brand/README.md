# Taxiro brand assets (original designs, made for this site)

Main logo used on the site: **v3 "Medallion"** (gold coin ring with a crowned T, slanted gold
wordmark), chosen by the owner. Copies used by the site: `assets/taxiro-logo.svg`, `assets/taxiro-mark.svg`,
`assets/favicon.svg`, `assets/apple-touch-icon.png`, `/favicon.ico`.

| Variant | Idea | Files |
|---|---|---|
| v1 "Ticket badge" | gold rounded-square badge, bold T with motion cuts, gold X in wordmark | `logo_v1.svg/.png`, `logo_v1_icon.svg`, `logo_v1_icon_512.png`, `logo_v1_wordmark.svg` |
| v2 "Wild cross" | diamond emblem, crossing gold/white X, airy wordmark | `logo_v2.svg/.png`, `logo_v2_icon.svg`, `logo_v2_icon_512.png`, `logo_v2_wordmark.svg` |
| **v3 "Medallion"** (main) | gold coin ring, crowned T, slanted gold wordmark | `logo_v3.svg/.png`, `logo_v3_icon.svg`, `logo_v3_icon_512.png`, `logo_v3_wordmark.svg` |

Small-size mark (simplified v3: gold coin with T, **no crown**), used for the favicon and any tiny
placement: `favicon.svg`, `favicon.ico` (16/32/48), `favicon-32.png`, `favicon-180.png` (apple touch),
`favicon-512.png`. `review/favicon_sizes.png` shows it at 16–96 px. The earlier v2-based favicon set is
archived in `old_v2_favicon/` (not used).

PNGs are transparent: full logos 1024 px wide, icons 512×512.
Wordmark letters are outlined from Space Grotesk (SIL Open Font License 1.1), so the SVGs need no font.
Regenerate SVGs with `python3 brand/make_logos.py` (needs fontTools + brotli).
`review/variants_sheet.png` is the side-by-side comparison on the dark site background.
No trademark search has been done for the name or marks.
